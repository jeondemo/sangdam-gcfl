# 과천외국어고등학교 진학상담 프로그램

수시 지원결과 4개년(2023~2026학년도)으로 **성적이 비슷했던 졸업생이 어디에 지원해 어디에 붙었는지**를 보여 주는 상담 도구입니다.
과천여고 프로그램에서 수시 부분만 떼어 외고 자료 양식에 맞춰 새로 만든 **별도 프로그램**입니다 — 저장소·스프레드시트·열쇠가 전부 따로이고 여고 자료와 섞이지 않습니다.
정시·모의고사·과목 선택 기능은 없습니다.

## 구성

```
index.html          화면 뼈대
config.js           배포 주소·학교 표기 (이 파일만 학교마다 다릅니다 · 저장소에 올리기 전에 주소를 넣으세요)
crest.png           학교 문장 (지금은 자리표시 — 실제 파일로 바꾸세요)
css/app.css         스타일
js/main.js          화면 흐름 · 관리자 · 저장
js/parse.js         외고 파일 읽기 (수시합격현황 · 내신 석차) · 5등급 → 9등급 환산 곡선
js/xlfix.js         한셀(HCell)로 저장한 .xlsx 손보기
js/match.js         유사 학생 탐색·집계
js/render.js        화면 조각
js/codec.js         전송·저장용 압축
js/api.js           Apps Script 통신
js/store.js         브라우저 저장(IndexedDB)
gas/Code.gs         스프레드시트에 붙이는 서버 스크립트
vendor/             SheetJS
```

## 설치 (처음 한 번)

1. 새 Google 스프레드시트를 만들고(외고 담당자 계정 권장) 확장 프로그램 → Apps Script 에 `gas/Code.gs` 내용을 붙여 넣습니다.
2. 편집기에서 `설치` 함수를 한 번 실행합니다. 스프레드시트 `설정` 시트에 **교사용키·관리자키**가 생깁니다.
3. 배포 → 새 배포 → 웹 앱 → 「액세스 권한: 모든 사용자」로 배포하고, 나온 `.../exec` 주소를 `config.js` 의 `GAS_URL` 에 넣습니다.
4. 이 폴더를 GitHub Pages 저장소(외고 전용)에 올립니다. `.gitignore` 가 엑셀 파일을 막지만, **자료 파일은 저장소 폴더에 아예 두지 마세요.**
5. 관리자 주소 `https://<계정>.github.io/<저장소>/?admin=관리자키` 로 들어가 지원결과를 올립니다.
6. 선생님들께는 `https://<계정>.github.io/<저장소>/?k=교사용키` 를 돌립니다.

코드를 고친 뒤 GAS 를 다시 배포할 때는 「배포 관리 → 새 버전」으로 해야 주소가 안 바뀝니다. 화면 파일(html·js·css)만 고쳤으면 GAS 는 손댈 것 없습니다.

## 관리자 — 지원결과 올리기

학년도별 「수시합격현황」 파일(재학생·졸업생 시트가 든 것)을 올립니다. 엑셀 저장본과 **한셀 저장본 모두** 읽습니다.
- 한 파일이 한 학년도입니다. **올리면 서버 자료가 통째로 바뀌므로** 볼 학년도를 전부 한꺼번에 고르세요. 한 번에 여러 파일을 골라도, 한 파일씩 차례로 골라도 되고(아래에 쌓입니다), 같은 학년도를 다시 고르면 그 학년도만 바뀝니다.
- 해마다 열 배치가 달라도(2023: 학번 있음 · 1차/최종 / 2024~: 최초·추가·최종 / 2026: 수능최저 P·F) 머리글을 읽어 찾습니다.
- 학번이 없는 해는 내신 8개 값이 같은 연속 행을 한 학생으로 봅니다(파일이 학생별로 묶여 있습니다).
- **이름·학번·주민등록번호는 읽지 않습니다.** 서버에는 학년도·내신·지원 내역만 갑니다. 재학(전교과)·졸업특기 시트는 아예 열지 않습니다.
- 결과는 「1차 → 최초 → 추합n → 최종」 순서로 읽어 합격·추합·불합으로 정리하고, 예비번호(「예12」)와 최저(최저N·F)를 따로 답니다. 최종 칸이 빈 줄은 「결과 없음」으로 남깁니다.
- 6월·9월 모평 열은 쓰지 않습니다(2024 파일은 `#REF!`).

## 교사 — 내신 석차 파일

학교 성적 프로그램에서 내려받은 「○학년 내신석차」 .XLS(또는 「재학(전교과)」 시트가 든 .xlsx)를 표지에 올립니다.
- **학년별로 따로 보관**합니다. 올린 파일의 학년만 바뀌고 다른 학년은 그대로입니다. 사이드바에서 학년별로 지울 수 있습니다.
- 전학년 값이 전부 5 이하이면 5등급제(2025년 입학 이후) 파일로 봅니다. 그 학생은 카드에 5등급을 크게, **9등급 환산을 괄호로** 보여 주고, 유사 학생 매칭은 환산값으로 합니다.
- 성적이 「★」로 비어 있는 학생은 목록에는 나오지만 상담 화면에서 그렇다고 알려 줍니다(9등급을 직접 넣으면 볼 수 있습니다).
- 명단은 이 브라우저(IndexedDB)에만 남고 서버로 가지 않습니다. 「이 컴퓨터에 기억」을 끄면 창을 닫을 때 사라집니다.

### 5등급 → 9등급 환산

5등급 평균을 산술로 바꾸는 게 아닙니다(과목마다 등급 경계가 달라 평균끼리는 대응이 없습니다).
파일에 든 **석차백분율**을 이 학교 졸업생 2,069명(2015~2022년 졸업)의 「석차백분율 → 9등급 전학년 평균」 곡선에 넣습니다.
1% 마다 중앙값을 잡아 단조가 되게 다듬은 표가 `js/parse.js` 의 `PCT_TO_9` 입니다. 실제 값과의 평균 오차 0.10, 90%가 0.19 이내이고, 해가 바뀌어도 같은 구간의 차이가 0.2 안쪽입니다.
1학년 1학기 석차는 졸업 때 석차와 다를 수 있습니다 — 상담용 근사치로 읽어 주세요.

## 화면

- **유사 학생** — 내신(9등급 전학년)이 가까운 졸업생 30명(40·50명 선택)의 수시 카드 전부. 「합격 있음 / 전부 불합」으로 거르고, 카드를 누르면 크게 봅니다. 「재수」 표시는 졸업생 시트에서 온 지원입니다.
- **대학·전형** — 대학 × 전형 갈래별 지원·합격·합격자 내신·최저미달.
- **카드 배분** — 갈래별 지원 비중과 합격 비중. 전형 이름은 대학마다 달라(네오르네상스·다빈치·KU자기추천 …) 이름을 보고 종합·논술·특기자·교과·실기·고른기회로 묶습니다(`parse.js` `trackOf`). 원래 이름은 카드에 그대로 나옵니다.
- **희망 계열** — 어문 / 사회·상경 / 자연·의약 / 예체능 / 기타. 외고는 인문사회에 몰리므로 어문과 사회·상경을 갈랐습니다(`parse.js` `gyeyeol`).

## 대학별 합격생

사이드바 「보기」에서 **대학별 합격생**을 누르면, 대학 이름으로 그 대학 지원 기록을 찾습니다.
- 「서울대」「서울대학교」 모두 됩니다. 앞에서부터 맞는 이름을 먼저 세우므로 동서울대·서울시립대가 섞이지 않습니다.
  줄임말(외대·이대·숙대·성대·고대·연대·시립대)은 풀어서 찾고, 캠퍼스가 둘인 곳은 본교를 먼저 엽니다(옆 칩으로 분교).
- 요약(합격자 수·지원·건별 합격률·합격자 내신 범위와 가운데 값), 전형 갈래별 표, **합격 목록을 내신(9등급 전학년) 좋은 순**으로 보여 줍니다.
- 거르기: 합격·추합만 / 전체 지원(불합은 흐리게) · 전형 갈래 · 학년도.
- 학생 상담에서 학생을 골라 두었거나 내신을 넣어 두었으면, 목록 안 그 내신 자리에 **파란 표시 줄**이 끼어듭니다.
- 학생 상담의 「대학·전형」 탭에서 대학 이름을 누르면 이 화면으로 넘어옵니다.
- 자료에 이름이 없으므로 목록에도 이름은 없습니다.

**화면 오가기**
- 대학 화면 오른쪽 위 **「← 대학 목록」**으로 검색 첫 화면으로, 학생 상담에서 넘어왔으면 **「← ○○○ 상담으로」**로 보던 자리(탭·스크롤 그대로)로 돌아갑니다.
- 브라우저 뒤로 가기(마우스 옆 버튼·Alt+←)·앞으로 가기도 같은 순서로 움직입니다.
- 메뉴의 「대학별 합격생」을 누르면 전에 보던 대학이 남지 않고 늘 대학 목록부터 시작합니다.

## 한계

- 수능 성적이 지원결과 파일에 없어(모평만 일부) 유사 학생 매칭은 내신만으로 합니다.
- 2024학년도 파일에는 졸업생(재수) 시트가 없어 그 해 재수생 실적은 빠집니다.
- 학번이 없는 해에 내신 8개 값이 모두 같은 두 학생이 붙어 있으면 한 사람으로 읽힙니다(드뭅니다).
- 유사 학생 30명 기준으로도 대학×전형 조합당 표본이 1~2건인 경우가 많습니다. **실제 사례를 보여 주는 용도이지 합격 확률로 읽을 수 없습니다.**
